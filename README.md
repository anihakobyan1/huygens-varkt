# Автопилот зонда «Гюйгенс» в KSP

Проект по дисциплине ВАРКТ (МАИ, М8О-108БВ-26), команда «Сатурн».
Скрипт `autopilot.py` повторяет в Kerbal Space Program циклограмму спуска зонда «Гюйгенс»
на Tekto (аналог Титана из Outer Planets Mod) и записывает телеметрию 10 раз в секунду.

## Что нужно

* KSP 1.12.x с модами **Outer Planets Mod** и **kRPC** (ставятся через CKAN);
* Python 3.10+ и библиотека kRPC **той же версии, что и мод**: `pip install krpc==<версия мода>`.

## Подготовка зонда

Ступени в порядке срабатывания («пробела»):
1. основной купол;
2. разделитель под теплозащитным щитом;
3. стабилизирующий купол.

Корневая деталь — зонд. У зонда должен быть режим SAS «ретроград».

## Запуск

1. Поставить зонд на орбиту Tekto выше 95 км (Alt+F12 → Cheats → Set Orbit).
2. В окне kRPC в игре нажать **Start server**.
3. В папке проекта: `python autopilot.py`
4. Свести зонд с орбиты. Дальше скрипт сам:
   * на 62,7 км раскроет основной купол;
   * на 60,8 км отстрелит щит;
   * на 49,1 км обрежет основной купол и раскроет стабилизирующий;
   * через 2 с после посадки остановится.

## Результат

* `data/ksp_telemetry.csv` — телеметрия: время, высота, скорость, плотность, скоростной напор,
  сила сопротивления, масса, этап, состояние куполов;
* `data/ksp_body.json` — параметры планеты из игры (GM, радиус, профиль плотности).
