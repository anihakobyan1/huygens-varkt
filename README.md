# Спуск зонда «Гюйгенс» на Титан — автопилот для KSP
 
Проект по дисциплине «Введение в авиационную и ракетно-космическую технику»
(МАИ, институт № 8, группа М8О-108БВ-26), команда «Сатурн».
 
Спуск «Гюйгенса» повторяется в Kerbal Space Program на спутнике **Tekto** из мода
Outer Planets Mod — игровом аналоге Титана. Автопилот раскрывает купола по циклограмме
настоящего зонда и записывает телеметрию 10 раз в секунду для сравнения с математической моделью.
 
## Файлы
 
| Файл | Кто запускает | Что делает |
|---|---|---|
| `autopilot.py` | физик, в игре | автопилот спуска + запись телеметрии |
| `prepare_titan_density.py` | программист, один раз | таблица плотности Титана из измерений прибора HASI |
| `event_altitudes.py` | программист, до автопилота | высоты событий на Tekto с той же плотностью воздуха, что на Титане |
| `data/HASI_L4_ATMO_PROFILE_DESCEN.TAB` | — | измерения зонда «Гюйгенс» (архив NASA PDS) |
| `data/titan_density_profile.csv` | — | плотность Титана по слоям 1 км (результат `prepare_titan_density.py`) |
 
## Установка
 
Python 3.10 или новее:
 
    pip install -r requirements.txt
 
Версия библиотеки `krpc` должна совпадать с версией мода kRPC в игре:
`pip install krpc==<версия мода>` (версия видна в CKAN).
 
## Расчёт высот событий (программист)
 
    python prepare_titan_density.py
    python event_altitudes.py
 
Событие на Титане → высота на Tekto с той же плотностью воздуха:
 
| Событие | Титан | Tekto |
|---|---|---|
| Ввод основного купола | 159 км | 63,1 км |
| Отстрел теплозащитного щита | 152,5 км | 61,0 км |
| Смена на стабилизирующий купол | 111 км | 49,1 км |
 
Эти высоты стоят в `autopilot.py`. После первого полёта появится `data/ksp_body.json`
с плотностью прямо из игры — тогда `event_altitudes.py` уточнит высоты по ней.
 
## Полёт в KSP (физик)
 
1. **Моды** (через CKAN): Outer Planets Mod и kRPC, KSP 1.12.x.
2. **Зонд.** Корневая деталь — зонд с режимом SAS «ретроград» (например, OKTO2 или HECS).
   Ступени в порядке срабатывания:
   1. основной купол;
   2. разделитель под теплозащитным щитом;
   3. стабилизирующий купол.
3. **Орбита.** Alt+F12 → Cheats → Set Orbit → Tekto, высота больше 95 км.
4. **Сервер.** В окне kRPC в игре нажать **Start server**.
5. **Запуск** из папки проекта:
       python autopilot.py
 
6. Свести зонд с орбиты. Дальше скрипт сам ведёт спуск и останавливается через 2 с после посадки.
## Результат полёта
 
* `data/ksp_telemetry.csv` — время, высота, скорость, плотность воздуха, скоростной напор,
  сила сопротивления, масса, номер этапа, состояние куполов;
* `data/ksp_body.json` — параметры Tekto из игры: GM, радиус, плотность атмосферы по высотам.
Этапы в столбце `phase`: 0 — вход на щите, 1 — основной купол со щитом,
2 — основной купол без щита, 3 — стабилизирующий купол, 4 — на поверхности.
